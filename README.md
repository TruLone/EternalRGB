# EternalRGB
The absolute best malware i've ever made, and my final contribution to the GDI community. 

# Description
* EternalRGB is essentially what happens if you combine EternalRed + EternalGreen + EternalBlue.
* It is insanely destructive, more destructive than anything i've ever made.
* It enumerates through all of the disks connected to the system and corrupts their data and overwrites their bootsectors.
* Corrupts the entire registry of the system, only leaving HKEY_LOCAL_MACHINE intact.
* Randomizes through 18 GDI payloads, 24 layered shaders, 23 audio sequences.
* Has a chaotic teardown at the final payload.
* Features a custom MBR that cycles through 6 different effects.
